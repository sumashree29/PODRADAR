# 🎙 PodRadar

A personal AI YouTube agent that summarizes videos with one hotkey press.

## What it does
- Press Win+Shift+P anywhere on your laptop
- Type any request like "Andrew Huberman sleep" or "Kunal Kushwaha docker"
- AI finds the video, pulls the transcript, gives a clean dark-themed summary
- Daily 6 PM auto-check across 41 subscribed channels
- Desktop notifications with 4-level priority system
- Runs 100% locally — no subscription, zero cost

## Tech Stack
· Python 
· Groq API (Llama 3.3 70B) 
· YouTube Data API v3 tkinter 
· plyer 
· youtube-transcript-api 
· ddgs  

## Setup
1. Install Python 3.11 from python.org — tick Add to PATH
2. Double-click setup.bat — installs all libraries
3. Double-click start_podradar.vbs — enter your API keys once
4. Press Win+Shift+P anywhere — done

## Free API Keys needed
- Groq API → https://console.groq.com
- YouTube Data API → https://console.cloud.google.com
